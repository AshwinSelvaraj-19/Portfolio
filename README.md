## Overview

This is the personal portfolio of **Ashwin Selvaraj**, a BCA student and software developer interested in building practical software, AI-powered applications, and security-focused systems.

The portfolio is designed as an interactive visual experience rather than a traditional static portfolio.

It combines:

- Interactive 3D environments
- Project case studies
- Animated UI components
- Technology skill displays
- Responsive layouts
- Smooth scrolling
- Bilingual content
- Interactive project previews
- Custom visual elements
- Direct contact and social connections

The goal is to present both **what I build** and **how I approach software development**.

# 🎨 Design

The portfolio intentionally avoids a conventional dashboard-style design.

The interface is built around a physical workspace concept where portfolio information is integrated into the environment.

### Design principles

- Minimal visual clutter
- Strong typography
- Physical / spatial UI elements
- Subtle animation
- Interactive objects
- Clear project hierarchy
- Responsive layouts
- Performance-conscious effects

The 3D environment acts as the visual foundation while the HTML interface provides the actual navigation and content.
