Design Direction

The portfolio is built around one idea:

The portfolio itself should demonstrate what I can build.

Rather than using a traditional portfolio structure, the website treats the interface as an interactive environment.

The design combines:

3D elements

Spatial UI

Motion

Interactive components

Project storytelling

Physical-inspired interface elements

Minimal information density

Responsive design

The objective is not to fill the website with unnecessary sections.

The objective is to make the important parts memorable.
